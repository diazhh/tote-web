**resolveDrawId(slotId) — returns `{ id, status } | null`:**
```javascript
async function resolveDrawId(slotId) {
  const slot = SLOTS[slotId];
  if (!slot) return null;

  const today = getVenezuelaDateString(); // returns 'YYYY-MM-DD'

  const draw = await prisma.draw.findFirst({
    where: {
      gameId: slot.gameId,
      drawDate: new Date(today),
      drawTime: slot.drawTime,
    },
    select: { id: true, status: true },
  });

  return draw ? { id: draw.id, status: draw.status } : null;
}
```

**normalize(payload) — full implementation:**

The function must:
1. Validate `payload.plays` exists and is a non-empty array. If not, return `{ rejected: true, reason: 'Payload must contain a non-empty plays array' }`.
2. Iterate over `payload.plays` — for each play:
   a. `parseInt(play.drawSlotId, 10)` — if `isNaN(slotId)` or `slotId < 1` or `slotId > 48` or `!SLOTS[slotId]`, return `{ rejected: true, reason: 'Invalid drawSlotId: ${play.drawSlotId} — valid range is 1-48' }`.
   b. Call `resolveDrawId(slotId)` — if null, return `{ rejected: true, reason: 'No draw found for slot ${slotId} (${SLOTS[slotId].gameName} ${SLOTS[slotId].drawTime}) today' }`.
   c. Check draw status — if `['DRAWN', 'CANCELLED', 'CLOSED'].includes(draw.status)`, return `{ rejected: true, reason: 'Draw for slot ${slotId} is ${draw.status} — bets not accepted' }`.
   d. Call `prisma.gameItem.findFirst({ where: { gameId: slot.gameId, number: String(play.number) }, select: { id: true, multiplier: true } })` — if null, return `{ rejected: true, reason: 'Number "${play.number}" not found in game ${slot.gameName}' }`.
   e. Push `{ draw, slot, gameItem, play }` to `resolvedPlays` array.
3. After ALL plays validated successfully, build and return:
```javascript
{
  drawId: resolvedPlays[0].draw.id,
  externalTicketId: String(payload.ticketId),
  totalAmount: resolvedPlays.reduce((sum, rp) => sum + Number(rp.play.amount), 0),
  providerData: payload,
  details: resolvedPlays.map(rp => ({
    gameItemId: rp.gameItem.id,
    amount: Number(rp.play.amount),
    multiplier: Number(rp.gameItem.multiplier),
    drawId: rp.draw.id,
  })),
}
```

Key implementation details:
- Per D-03: NEVER throw for validation failures. Only throw for unexpected errors (let Prisma connection errors etc. propagate naturally).
- Per D-05: GameItem lookup uses `number` field only (`String(play.number)`). The `animal` field from the payload is ignored in the lookup — it is preserved in `providerData` for reference.
- Per D-01: `drawId` at top level = first play's draw.id. Each detail has its own `drawId`.
- Per D-02/D-06: Early return on first validation failure = entire ticket rejected.
- Per ADAPT-04: `parseInt(play.drawSlotId, 10)` handles string-to-number coercion.
