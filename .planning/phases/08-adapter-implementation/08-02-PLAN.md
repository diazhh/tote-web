**Part B: Modify `backend/src/services/webhook.service.js`**

Two changes:

**Change 1 — D-04 rejection check (lines 109-111):**

Replace:
```javascript
    const normalized = await adapterModule.normalize(JSON.parse(rawPayload));
    const ticket = await createWebhookTicket(normalized, log.id);
```

With:
```javascript
    const normalized = await adapterModule.normalize(JSON.parse(rawPayload));

    // D-04: Check adapter rejection before ticket creation
    if (normalized && normalized.rejected) {
      await prisma.webhookLog.update({
        where: { id: log.id },
        data: { status: 'FAILED', errorMessage: normalized.reason || 'Rejected by adapter' },
      });
      logger.warn(`[webhook] Payload rejected by adapter "${slug}" (logId=${log.id}): ${normalized.reason}`);
      return { status: 'rejected', logId: log.id, reason: normalized.reason };
    }

    const ticket = await createWebhookTicket(normalized, log.id);
```

**Change 2 — D-01 drawId in TicketDetail (lines 44-49):**

In the `createWebhookTicket` function, modify the details.create map to include drawId:

Replace:
```javascript
      details: {
        create: normalized.details.map((d) => ({
          gameItemId: d.gameItemId,
          amount: d.amount,
          multiplier: d.multiplier,
          prize: 0,
          status: 'ACTIVE',
        })),
      },
```

With:
```javascript
      details: {
        create: normalized.details.map((d) => ({
          gameItemId: d.gameItemId,
          amount: d.amount,
          multiplier: d.multiplier,
          prize: 0,
          status: 'ACTIVE',
          ...(d.drawId ? { drawId: d.drawId } : {}),
        })),
      },
```

This conditionally includes drawId only when present, so existing non-virtuales adapters that don't provide per-detail drawId continue to work.
