--- FILE 1: backend/src/services/webhook.service.js ---

Exports: dispatchWebhook(apiSystem, rawBody, headers)
Purpose: log-first webhook dispatch with dynamic adapter loading

Implementation requirements:
- __dirname equivalent at top: fileURLToPath(import.meta.url) pattern (same as index.js lines 103-106)
- Step 1 (always): prisma.webhookLog.create({ data: { apiSystemId: apiSystem.id, rawPayload: rawBody.toString('utf8'), headers: headers ?? null, status: 'DISCOVERED' } })
- Step 2: attempt dynamic import of adapter:
    const adapterPath = path.resolve(__dirname, '../webhooks/adapters/' + slug + '.adapter.js');
    adapterModule = await import(adapterPath);
  On ERR_MODULE_NOT_FOUND: log.info discovery mode, return { status: 'discovery', logId: log.id }
  On other error: update log to FAILED with errorMessage, return { status: 'failed', ... }
- Step 3 (adapter found): adapter.normalize(JSON.parse(rawPayload)) then createWebhookTicket(normalized, log.id)
  On success: update log to PROCESSED, return { status: 'processed', logId, ticketId }
  On error: update log to FAILED, return { status: 'failed', logId, error } — DO NOT rethrow

Private function createWebhookTicket(normalized, logId):
- Check for existing ticket: prisma.ticket.findFirst({ where: { drawId: normalized.drawId, externalTicketId: normalized.externalTicketId, source: 'WEBHOOK_PUSH' } })
- If found: update log to DUPLICATE, return existing ticket
- If not found: prisma.ticket.create with source: 'WEBHOOK_PUSH', drawId, externalTicketId, totalAmount, totalPrize: 0, status: 'ACTIVE', providerData: normalized.providerData ?? null, details.create mapping normalized.details to { gameItemId, amount, multiplier, prize: 0, status: 'ACTIVE' }

CRITICAL: The adapter contract (what normalize() must return):
  { drawId: string, externalTicketId: string, totalAmount: Decimal|number, providerData?: object, details: [{ gameItemId: string, amount: Decimal|number, multiplier: Decimal|number }] }

--- FILE 2: backend/src/controllers/webhook.controller.js ---

Exports: named export `receive` (async function)
Purpose: thin HTTP handler

Implementation:
- Import dispatchWebhook from '../services/webhook.service.js'
- Import logger from '../lib/logger.js'
- async function receive(req, res):
    try:
      const result = await dispatchWebhook(req.apiSystem, req.body, req.headers);
      return res.status(200).json({ received: true, logId: result.logId });
    catch err:
      logger.error('[webhook] Unhandled error in receive handler:', err);
      return res.status(200).json({ received: true });
- Always returns HTTP 200 after auth passes — processing errors are in WebhookLog.status
