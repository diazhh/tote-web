The two changes needed in index.js:
  1. In the IMPORTAR RUTAS section (around line 174, after other imports):
     import webhookRoutes from './routes/webhook.routes.js';

  2. In the REGISTRAR RUTAS section, BEFORE app.use(express.json()):
     app.use('/api/webhooks', webhookRoutes);

  PITFALL: If app.use('/api/webhooks', webhookRoutes) is placed AFTER line 99
  (app.use(express.json())), express.json() will consume the body and req.body
  will be a plain Object instead of a Buffer. webhook.service.js calls
  rawBody.toString('utf8') which throws TypeError on a plain Object.
