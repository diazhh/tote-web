Key Prisma queries the script will use:
- Enum verification (must run FIRST per F-10):
  `await prisma.$queryRaw\`SELECT unnest(enum_range(NULL::"DrawStatus")) AS v\`;`
  Abort if any row has `v === 'PUBLISHED'`.
- Remaining draws to process (resumable per D-01):
  ```
  SELECT d.id, d."drawnAt", d."closedAt"
  FROM "Draw" d
  LEFT JOIN "DrawFinancial" df ON df."drawId" = d.id
  WHERE d.status = 'DRAWN'
    AND d."prizesProcessed" = true
    AND (df."totalizedAt" IS NULL)
  ORDER BY d."drawDate" ASC, d."drawTime" ASC
  ```
- Reconciliation query (post-write, D-04):
  ```
  SELECT df."drawId",
         df."totalSales"::text AS materialized_sales,
         (SELECT COALESCE(SUM(td.amount), 0)::numeric(12,2)
          FROM "TicketDetail" td
          JOIN "Ticket" t ON t.id = td."ticketId"
          WHERE td."drawId" = df."drawId"
            AND t.status != 'CANCELLED')::text AS live_sales
  FROM "DrawFinancial" df
  ```

Service functions to invoke per draw (from Plan 11-02):
- `await computeAndUpsertSales(draw.id, draw.closedAt)`
- `await computeAndUpsertPrizes(draw.id, draw.drawnAt)` — historical totalizedAt = drawnAt per D-05

CLI surface (per D-02):
- `--dry-run` — compute everything, print summary, write nothing.
- `--confirm` — required for actual writes; without it, the script aborts with exit code 2 and a clear message.
- `--chunk-size N` (optional, default 100, range 50-500 per CONTEXT.md "Claude's Discretion").
