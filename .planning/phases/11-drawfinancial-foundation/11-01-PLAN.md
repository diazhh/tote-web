## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | DrawFinancial row mutation after totalizedAt is set | accept | Phase 11 enforces freeze via worker logic (D-16); DB-level row-level locking is over-engineering for current operator threat model (single admin role). |
| T-11-02 | Information disclosure | Decimal precision drift on Decimal(12,2) amounts | mitigate | Use Prisma `@db.Decimal(12,2)` matching DrawStats; decimal.js used in app-side arithmetic to avoid JS float conversion errors (F-4 mitigation extends to Phase 12 but the dep is added here). |
| T-11-03 | Repudiation | Backfill writes without audit trail | accept | Plan 11-04 produces a reconciliation CSV; BackfillRun audit table deferred per CONTEXT.md "Deferred Ideas". |
| T-11-04 | Denial of service | Schema migration locks Draw table during ALTER | accept | New tables are additive (CREATE TABLE only) — no ALTER on Draw beyond adding reciprocal relations, which Prisma materializes as foreign key constraints on the new tables, not Draw itself. Migration window is short. |
